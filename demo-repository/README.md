# 知枢固定演示仓库

这是一个故意保留边界缺陷的最小 JavaScript 项目，用于重复演示知枢的任务编排、权限审批、测试执行和 Artifact 投影能力。

## 业务规则

订单折扣率必须限制在 `0` 到 `0.5` 之间：

- 负数按 `0` 计算；
- 大于 `0.5` 的值按 `0.5` 计算；
- 合法折扣率保持不变。

初始实现没有处理这两个边界，测试中保留了对应失败用例。验收脚本每轮都会复制一份全新的工作区，因此 Agent 的修改不会污染本模板。

## 本地查看基线

```bash
npm test
```

基线预期有两个失败用例；完成写入任务后，测试应全部通过。
